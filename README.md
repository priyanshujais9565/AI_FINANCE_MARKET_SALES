# AI_FINANCE_MARKET_SALES
📊 AI Finance Market Analysis
🚀 Overview

This project analyzes the financial performance and stock impact of major AI companies like OpenAI, Google, and Meta using a synthetic dataset.

It focuses on:


#R&D Spending 💰
AI Revenue 📈
Stock Market Impact 📉📊
Event-based analysis (e.g., GPT-4 release)
📁 Dataset

The dataset used:

ai_financial_market_daily_realistic_synthetic.csv

It contains:

Date
Company
R&D_Spending_USD_Mn
AI_Revenue_USD_Mn
AI_Revenue_Growth_%
Stock_Impact_%
Event
🛠️ Technologies Used
Python 🐍
Pandas
Matplotlib
Seaborn

📌 Key Analysis Performed


1. Data Cleaning & Preparation
Converted Date column to datetime format
Created a Year column
Checked missing values

2. R&D Spending Analysis
Total R&D spending by each company
Visualized using bar charts

3. Revenue Analysis
Total AI revenue generated by companies
Comparison between companies

4. Stock Market Impact
Date-wise stock impact visualization
Company-wise stock trends:
OpenAI
Google
Meta

5. Event-Based Analysis
Identified major events (e.g., GPT-4 release)
Analyzed their effect on stock performance
 
 6. Revenue Growth Analysis
Scatter plots for AI revenue growth
Trend analysis for each company
 
 7. Correlation Analysis
Heatmap to identify relationships between variables
📊 Sample Visualizations
Bar Charts (R&D vs Revenue)
Line Plots (Stock Impact over time)
Scatter Plots (Revenue Growth)
Heatmap (Correlation Matrix)
